# Coralogix Homebrew Tap

> **`cx` has moved to [homebrew-core](https://github.com/Homebrew/homebrew-core/blob/main/Formula/c/cx.rb).**
> You no longer need this tap.

## Installation

```sh
brew install cx
```

## Already installed from this tap?

Nothing to do. Your next `brew update` (or `brew upgrade`) moves `cx` to
`homebrew/core` automatically, through [`tap_migrations.json`](tap_migrations.json).
Then upgrade as usual:

```sh
brew upgrade cx
```

Optionally, remove the tap after the move:

```sh
brew untap coralogix/tap
```
